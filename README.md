# The Prophetic Archive - processed content

This repository contains the processed structured content prepared for The Prophetic Archive app.

## Collections

- `prophetic-scrolls`: 320 unique Scroll numbers represented by 325 physical documents because Scrolls 7, 11, 15, 23, and 320 have Part 2.
- `special-writings`: 141 documents.
- `translation-alerts`: Introduction plus Translation Alerts 001-061; numbered items and compilation subheadings are preserved.
- `monthly-letters`: 199 documents using the printed month/year.

## Preliminary Pages

The preliminary Pages that belong before Scroll 1 are not included yet because their source file was not present in the supplied processing set. They have not been fabricated.

## Repository policy

DOCX editing masters are intentionally excluded. This repository contains structured JSON, manifests, processing notes and validation data needed by the app. Large PDFs and original scans should be distributed as release assets or equivalent static/object storage rather than committed to normal Git history.
