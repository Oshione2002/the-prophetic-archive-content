# KJV Bible source provenance

## Text used by this build

The actual verse text in this generated package is downloaded from:

- Repository: `aruljohn/Bible-kjv`
- Pinned revision: `a9aa4e55afbb3e095f57e4b14cd1f22c5ee8d7c9`
- Upstream layout: one JSON file per canonical Bible book
- Expected canon: 66 books

The upstream repository describes the dataset as the King James Version. It
does not identify a specific printing or textual edition, so this package does
not claim that the source is an exact 1611 or exact standardized 1769 printing.

No verse wording is generated by AI. The builder copies source verse strings
into the archive structure and adds only identifiers, hierarchy, search blocks,
indexes, metadata, and checksums.

## Public-domain reference

eBible.org separately publishes a standardized 1769 King James Version
(protocanon only) and identifies it as public domain outside the United Kingdom.
That eBible edition is used here as a provenance/licensing reference, not as a
claim that this build's source repository is byte-identical to eBible's text.

Reference:
https://ebible.org/find/details.php?id=eng-kjv2006

## UK note

The KJV has a special Crown/letters-patent status in the United Kingdom.
Distribution/printing in the UK should be reviewed separately. This package is
technical material, not legal advice.
