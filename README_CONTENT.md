# The Prophetic Archive - processed content

This folder contains the split PDFs and structured JSON prepared for the app content repository.

## Collections

- `prophetic-scrolls/`: 320 unique Scroll numbers represented by 325 physical documents because Scrolls 7, 11, 15, 23, and 320 have Part 2. Clean PDFs, matching original scans, and JSON are separate.
- `special-writings/`: 141 split PDFs and 141 JSON files.
- `translation-alerts/`: Introduction plus Translation Alerts 001-061, split at actual document boundaries; JSON preserves numbered items and compilation subheadings.
- `monthly-letters/`: 199 split monthly-letter PDFs and 199 JSON files using the printed month/year.

## Preliminary Pages

The preliminary Pages that belong before Scroll 1 are **not included in this output** because they are not present in the source set used for this processing run. They have not been fabricated. Add them when their source file is supplied.

## GitHub

DOCX editing masters are intentionally excluded. For production, keep large original scans in GitHub Release assets (or equivalent object/static storage) rather than normal Git history. The manifests contain file sizes and SHA-256 hashes for the processed assets.
